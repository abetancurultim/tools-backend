1.  Objetivo
Describir los aspectos técnicos del servicio de firma electrónica.
2.  Descripción general del servicio
El WebService de firma electrónica es un servicio que permite recibir la información
necesaria y suficiente para la emisión de un certificado de firma electrónica y firma
de documentos.
Los componentes requeridos para la interacción se describen a continuación:
✓           Un cliente de WS desarrollado por la entidad autorizada siguiendo las
especificaciones de este documento.
✓           Un par de credenciales de autenticación válidas para poder acceder a los
servicios.
✓           La clave o contraseña debe ser generada a través de la plataforma de
administración de usuarios.
✓           El tipo de contraseña debe ser PasswordText.
3.  Requerimientos de canal seguro de comunicación
La comunicación entre el cliente de WS y el WebService debe realizarse mediante
un canal seguro SSL/TLS. (Versiones soportadas - TLS 1.2 y TLS 1.3).
El protocolo de comunicaciones utilizado para aplicar seguridad sobre el servicio es
WS-Security versión 1.1.
4.  Mecanismos de autenticación
✓           El cliente de WS agrega una cabecera WS-Security con usuario y clave.
✓           El WebService autentica al usuario.
✓           El cliente del WS recibe la respuesta del WebService.
